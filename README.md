# WhaleGirl–MaiBot Bridge

Windows 上的鲸鲸微信前台桥接：**麦麦负责思考和模型调用，鲸鲸负责微信监听与发送。**

这是从已有本地部署提取的独立源码仓库，不是两个上游项目的 Fork，也不包含它们的完整程序、运行时、模型或用户数据。**不是放进麦麦 plugins 文件夹就能独立运行的插件**：需要同时安装鲸鲸侧补丁、本地转发服务和麦麦插件。

## 功能

- 文字消息、普通图片转交麦麦；出站支持文字及单张图片/表情包。
- 图片模式：自动、`/识图` 请求后 60 秒内下一张图、关闭；收到的表情包仍忽略。
- 用户消息包含小写 `/v` 时，麦麦可调用鲸鲸配置的语音 API 回答；没有标记不能调用。
- 语音录音前将 Windows 默认录音及通信设备设为 `CABLE Output (VB-Audio Virtual Cable)`，失败取消。
- 本账号文字同步为“主人代发”的非触发上下文；机器人回声按近期发送记录排除。
- 手机网页 Key 认证、按会话人工接管、文字代发；可选 Cloudflare 临时 HTTPS 隧道。
- 队列去重、取消、权限检查；不确定的微信发送不自动重试。
- 提供 `Start-Whale-Mai.cmd` / `Stop-Mai.cmd` 和备份、还原工具。

**不包含本地 RVC、模型权重、合成环境、RVC API 或启动开关。** 麦麦自行选择是否及何时回表情包，不保证每条都回复。

## 支持范围与依赖

| 项目 | 当前基线 |
| --- | --- |
| 操作系统 | Windows，微信前台桌面必须可用 |
| 鲸鲸 | 本地提取基线 `4.0.8.1`，微信收发已自行配置成功 |
| 麦麦 | 源码部署 `1.4.3`、已初始化的宿主实例和机器人 |
| Python | 3.12+；各程序使用各自环境 |
| 麦麦 SDK | 使用 `maibot-plugin-sdk` 2.22.1+ 的网关、会话及上下文 API；不能把 manifest 的范围当成完整兼容性保证 |
| 语音可选依赖 | 鲸鲸原有语音 API 功能、VB-CABLE、微信录音快捷键配置 |
| 远程可选依赖 | 用户自行从官方取得 `cloudflared.exe`，放到 `tools/` |

原始本地副本没有上游 Git 元数据，因此没有虚构上游 Commit SHA。`SOURCE-PROVENANCE.json` 记录提取前文件哈希；同版本的其他发行包也可能有差异。安装器拒绝不匹配的版本，不能强行替换新版文件。

## 安装与使用

1. 先分别安装、运行并配置 [鲸鲸](https://github.com/Banan1cee/whale_girl) 与 [麦麦](https://github.com/Mai-with-u/MaiBot)。
2. 按 [人工安装教程](docs/INSTALL.md) 检查路径、预览文件替换、备份安装。
3. 在麦麦填写模型配置，在鲸鲸设置微信权限及可选语音 API。
4. 使用启动 CMD，在鲸鲸登录/连接微信。用图片设置 CMD 调整看图模式。
5. 关闭 CMD 停止麦麦及远程隧道，转发服务保持空闲；鲸鲸仍由用户手动断开或退出，不杀掉已有微信/鲸鲸进程。

本仓库安装器不会替你填写 API Key、覆盖人设、复制旧记忆或开启未授权会话。

## API 在哪里配置

| 功能 | 配置方 |
| --- | --- |
| 聊天、规划、图片识别、Embedding 等模型 | 麦麦 |
| `/v` 回答的语音合成 API、模型、音色 | 鲸鲸 |
| 微信读取和前台发送权限 | 鲸鲸 |
| 本地桥接 Token、远程网页 Key | 首次安装/启动时本机随机生成 |

鲸鲸已有的聊天 API 配置保留，但进入桥接路由的普通微信消息由麦麦处理，不复制鲸鲸 Key、不复用鲸鲸人设、不在麦麦故障时改用鲸鲸聊天 API。其他鲸鲸独立功能仍可能使用其已有配置；本插件不全局禁用它们。恢复安装备份后可恢复原路由。

## 限制与验证边界

- 需要 Windows 微信桌面；锁屏、桌面不可交互、目标会话校验失败会影响发送。
- 图文混合段/多图需要拆开；单张 PNG/JPEG/GIF/WebP 最多 8 MiB、1600 万像素。原始动图字节保留，微信可能显示为附件而非原生收藏表情。
- 同步仅支持本账号文字；两分钟内人工与机器人发送完全相同文字可能被当作回声。上下文同步不等于长期记忆导入。
- 网页代发需先人工接管。已开始的发送不能保证撤回；“已执行发送”不是微信服务端送达回执。
- 临时网址重启可能变化；没有域名/DNS 修改。Key 只在页面内存，不放 URL 或浏览器持久存储。
- 本次发布的隔离回归测试不向微信发送。未在全新第三方电脑验证安装或实际语音/表情包发送，不承诺所有同版本发行包即装即用。

## 更新、维护与隐私

本项目不承诺紧跟上游更新。其他 Agent 请先阅读 [AGENTS.md](AGENTS.md) 和 [维护手册](docs/MAINTENANCE.md)，按文件职责、接口和兼容检查自行适配，不直接覆盖新上游。

开发验证：`python -m unittest test_relay test_remote test_emoji test_distribution`；发布前运行 `python scripts/privacy_check.py`。仅提交源码，禁止提交 `data/`、`instance/`、`backups/`、个人配置、日志、密钥和聊天记录。详细变化见 [发布改动](docs/RELEASE-CHANGES.md)。
