# 独立发布整理范围

本次将本地已有桥接提取为独立源码目录，没有打包上游主仓库，没有改变开发机的运行工程。

保留：文字与图像转发、表情出站、API 语音 `/v` 授权、自身文字同步、人工接管、远程 Key 页面、一次性发送策略。

按发布要求做的变化：

1. 移除本地 RVC 导入、发送分支、合成服务、`/v1/audio/speech`、旧 `/adapter/voice`、模型和启动选项；保留鲸鲸 API 语音 `/adapter/whale-voice`。
2. 将机器绝对路径改为安装器生成的本机配置或相对安装路径。未复制配置、聊天历史、Token 或 API Key。
3. 不纳入旧 `setup_instance.py`，避免自动复制鲸鲸模型凭据和修改麦麦人设；安装器只部署桥接。
4. 新增版本门控安装/还原、启动脚本的实例识别、文档与隐私检查；保留原发送实现，不用新实现替代。
5. manifest 改为准确的 API 语音描述、独立仓库地址及 AGPL-3.0-only 声明；网页提供源码链接。
6. 只在发布副本中处理上述内容，旧工程和原有快捷方式未修改。

不承诺频繁跟进上游。基线来源与文件哈希见 `SOURCE-PROVENANCE.json`。版本升级时依照 `AGENTS.md` 和维护手册重新核对，不能仅修改支持版本数字。
